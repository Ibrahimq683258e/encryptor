How it works

How Cipher Encryption Works

Cipher is a 100% client-side file encryption tool that runs directly in your browser using the standard Web Crypto API.

  • Key Derivation: PBKDF2 with SHA-256 algorithm and 250,000 iterations for strong password hashing.
  • Cipher: AES-256-GCM authenticated encryption ensuring confidentiality and data integrity.
  • Zero Server Uploads: Your files and passwords never leave your computer.
  • Binary Specification: `.cipher` format contains a 4-byte header (`CPHR`), 1-byte version, 16-byte random salt, 12-byte random IV, preserved UTF-8 filename, and encrypted payload.
